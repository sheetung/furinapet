## 本轮：持续上移定格修复与动作变体

- 根因：漫步的垂直移动使用单次 `jumping`。840 ms 后采样器返回静止帧并停止计时，但窗口仍沿目标移动；同名 reaction 不触发动画重启。
- 修复：把 `airborne`（持续上移）、`falling`（持续下移/重力下落）与单次 `jumping` 分离。前两者循环腾空帧，抵达目标或结束下落才离开移动动画；不在每个运动 tick 重启动画。
- 新增控制中心动作：眨眨眼、歪头观察、闭眼小憩、开心庆祝；总计 9 组。这些是已有图像的专用帧序列/组合，不是新绘制的坐姿、躺睡或饮茶图。
- 新手势仅启用于内置芙宁娜，其他角色回退到原有 Reaction。公共 IPC 的 Reaction 类型保持不变。
- `npm test`：18 项通过。新增 30 秒持续上/下移动采样回归，确认不会返回静止帧或停止计时；验证新增手势与共享控制器传递。
- `npm run build`：通过。本轮修复尚未进行原生长距离移动实测，也未重建 Windows 程序；当前已运行程序仍是上轮版本。

## 生成来源与维护

本批 PNG 使用内置图像生成工具，以原 v2 图集和新待机为角色参考，要求真实透明背景、相同服饰与比例、完整头脚、固定镜头。未对 PNG 做脚本重绘；裁切和缩放由渲染样式完成。

提示词要点：待机 3×2 六帧呼吸/眨眼；挥手横向四帧抬手/摆手/收手；跳跃 3×2 五帧下蹲/起跳/顶点/落地/站定（末格留空）；思考 3×2 六帧托腮/侧看/眨眼/回正。所有组要求无文字、无背景、无相邻帧重叠。
