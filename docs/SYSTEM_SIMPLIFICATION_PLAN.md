# FurinaPet 结构简化与运行时优化计划

日期：2026-10-09。状态：代码及自动化验证完成；原生交互流畅度待实机确认。

## 目标与范围

按顺序完成统一控制中心导航、收敛动作执行状态、减少静止时的原生窗口查询；每阶段验证通过后进入下一阶段。保持现有功能、外观、动作时长、防打扰冷却以及 MCP/插件协议。

本轮不拆分 Rust 宿主和角色存储模块，不升级框架，不调整版本，不提交或推送。保留移动租约、串行写入队列、异步失效检查和配置恢复机制；持久化格式不变。

## 1. 统一控制中心导航

- App 独占主页、宠物、插件、智能体、设置五个页面状态，默认主页；React 统一渲染侧栏，保留顺序、图标和文案。
- 插件和智能体组件改为接收 active:boolean 的页面组件，保持挂载以保留查询结果及正在进行的操作，仅激活时输出内容。
- 删除导航 DOM 注入、MutationObserver、其他页面样式隐藏/恢复、模拟点击主页、重复导航监听及 extensionPageActive。
- 页面直接进入主内容区；插件配置弹窗继续 Portal 到 document.body，离开插件页关闭。
- 智能体仅激活时轮询，退出清理，迟到响应不更新已卸载组件。主窗口插件 Worker 不受页面切换影响。不引入路由库。

## 2. 收敛执行状态

- ActionCoordinator 独占动作抢占、阻断、取消、结果判定；优先级仍为用户100、智能体20、后台10。
- 行为执行器只遍历语义计划、调用处理函数及记录进度；删除独立 AbortController、评分抢占、force、interruptMargin、interrupt 通道和桥接取消监听。
- 内部接口 PetBrain.execute(plan,handler,signal) 使用协调器会话信号；等待与动作播放继续调用 session.wait/perform。
- 停止、隐藏、切换角色及拖拽通过协调器停止/阻断。保留 executor 快照字段 running、planId、goal、score、actionIndex，但它们不参与仲裁。
- 取消立即清空对应进度；旧任务迟到完成或异常不得清空新快照。结果沿用 ActionResult；清理未使用的 waitForAction。
- 行为目标评分、需求恢复、手势选择规则不变。

## 3. 优化静止采样

- 移动/停靠继续32ms循环及现有窗口跟随规则；鼠标感知独立48ms，慢窗口查询不阻塞注视。
- 隐藏、拖拽、下落、布局忙及动作播放期间，漫步在原生位置/尺寸读取前跳过几何查询。
- 静止等待最多每250ms检查设置与决策到期；未到期不读取几何。隐藏/设置未加载等待1000ms。
- 恢复移动重新建立时间基准，不累积静止时间。保留决策截止时间、五分钟拖拽位置保护、停靠冷却和写入有效性检查。
- 重力继续由独立落地请求和交互控制器处理；保持启用重力、拖拽释放及离开停靠后的落地。不新增跨控制器几何缓存。

## 验证与验收

- 浏览器反复切换五页：唯一高亮与唯一页面，插件配置弹窗正确关闭，智能体轮询退出停止，插件运行不因导航中断。
- 语义执行集成测试：用户抢占后台、同优先级替换、停止/隐藏/拖拽取消、等待取消、旧任务迟到失败及新快照保护。
- 虚拟时钟与端口计数：静止等待、动作播放及隐藏期间漫步几何查询为零；到期恢复、移动频率、停靠跟随、重力落地不变。
- 回归拖拽、停靠、气泡布局、重力、注视；启动Tauri开发版冒烟。
- pnpm test、pnpm build、cargo test --manifest-path src-tauri/Cargo.toml --locked、差异检查。性能结论仅按端口计数；未实测CPU不宣称CPU降幅。

## 后续调整：安静陪伴与重复权重（2026-10-09）

根据用户反馈“多动且随机”及“同一个动作做过之后应该减小权重”，追加以下调整：

- 芙宁娜角色配置降低活动度、好奇心及移动速度，提高短距离移动倾向；决策与移动后停留间隔为20–30秒。
- 动作播放不再将已有决策截止时间缩短到结束后约1.5秒，避免动作连续触发。
- 待机分数提高；当其他目标仅略高于待机时保持待机，随机选择范围从分差0.16缩小到0.06。自主待机仅保留低频眨眼，不再自动轮换歪头观察；手动动作仍可使用。
- 行为目标按最近两分钟的决策历史逐渐降低重复分数，插入一次待机不会清除惩罚，时间经过后恢复。
- 候选手势只在协调器确认播放完成后记录。重复权重采用原权重除以（1＋近期重复次数），近期记录在三分钟内逐渐衰减；保留冷却。取消或仅提出动作不计入完成历史。
- 必要需求恢复及用户明确意图不受随机候选淘汰。

验证：133项前端测试通过，前端构建及差异检查通过。新增测试覆盖启动待机、后续探索、20–30秒间隔、播放期间保留截止时间、非连续重复、权重随时间恢复及未执行手势不计数。此次未修改Rust；此前17项Rust验证结果仍属于上一阶段。

## 后续修正：注视尺寸一致（2026-10-09）

用户反馈注视鼠标时人物放大。检查资源发现新版待机的站立高度约190逻辑像素、脚底基准200；旧注视图的正面站立高度约198像素、脚底203。内置芙宁娜的16个注视方向现统一通过角色图帧渲染，以190/198比例和相同脚底基准显示，保留方向间的真实低头高度差异，不改变用户设置的整体缩放或导入角色。

135项前端测试、前端构建及差异检查通过；新增注视全方向比例/基准回归，扩展原图帧边界测试。资源合成对比保存为 `docs/gaze-scale-verification.png`，它验证资源比例，不代表原生窗口的实际截图。

## 后续优化：活动分离与持续需求恢复（2026-10-09）

- 消耗与恢复按实际活动计算，不再从画面推测：协调器执行步骤可显式标注活动，移动控制器提供真实移动/停靠活动。同样的等待画面可表示观察、空闲或休息；语义等待清回空闲，活动切换立即结算。
- 真实需求恢复使用同一个协调器会话，达到体力70%或对应口渴/饥饿25%才结束。饥渴65%进入、25%退出；精力35%进入、70%退出。休息使用安静等待，小憩和饮食保留现有动作。
- 普通后台行为让位，用户及智能体保持原优先级。停止、隐藏、切换角色和拖拽沿用协调器取消；仅记已经发生的恢复，需求仍可在下一次正常决策继续处理。
- 保持外部协议、角色兼容和运行期状态；不新增心情、持久化或配置化。

差异检查通过。Tauri开发版重新启动，Rust开发构建成功；已核对工作区debug进程及Vite提供的最新恢复和活动订阅模块。安装包未重新生成。

## 后续简化：移除插件系统（2026-10-09）

用户决定先聚焦桌宠核心，删除当前插件系统。控制中心仅保留主页、宠物、智能体、设置四页；移除插件页面、目录查询、安装/卸载、配置、Worker运行时、Rust插件宿主及SDK命令。旧插件用户数据不主动删除，也不再加载。

点击感知桥迁到 `src/pet/dom-bridge.ts`，分类后的点击和双击直接发送给Pet Brain，保留原生拖拽释放判定、单/双击时间窗口与清理机制。移除插件仲裁字段和意图来源；MCP、智能体、AI、动作、气泡及角色资源功能保留。Tauri开机启动与打开链接依赖仍是必要系统能力。

验证：149项前端测试、17项Rust测试及前端构建通过；新增直接点击/双击、拖动不误判点击及卸载后迟到释放不触发事件的回归。导航验证页改为四页与无插件启动检查。未重做新插件系统，未提交或推送。
