# 主线稳定化进度（2026-09-30）

范围：基于 main 的 v1.1.2，不合并实验美术分支，不引入 neuro。保留原有 v2 图集契约，内置芙宁娜的部分动作以独立透明图集替换，详见 [动作更新进度](MOTION_REFRESH.md)。以下是开发中改动，不代表已发布版本。

## 1. 动作控制

- 用户互动、组合动作、PetBrain 语义动作和后台直接反应共用 ActionPlayback。
- 优先级：用户 100、Agent 20、后台/插件/AI 10。同优先级的新动作替换旧动作；低优先级请求直接丢弃，不排队补播。
- 控制权覆盖整个序列，包括 idle 和 wait；取消会清理计时器、通知语义执行器并回到 idle。
- 停止、隐藏、角色切换取消当前播放；拖拽期间阻止新动作，拖拽结束并完成落地后恢复。
- 原生关闭桌宠窗口通过统一可见性设置处理，避免窗口隐藏但逻辑仍视为显示。
- PetBrain 不再通过固定 2600 ms 的 Rust 反应接口播放，实际显示与语义时长共用计时器。旧 IPC 保持默认 2600 ms，兼容已有插件/MCP。
- 漫步异步查询返回后核对播放代次，避免旧 tick 覆盖新动作；播放期间暂停漫步和视线跟随。
- AI 返回时检查配置变化、用户交互和播放优先级；服务端配置修订号使旧请求结果失效。请求本身仍可能在供应商端完成，并非网络请求撤销。

## 2. 升级与兼容

- 设置增加 schemaVersion=1；旧字段缺省迁移，异常数值归一化。同目录临时文件写入并同步后替换，保留上一份有效 .bak。
- 读取损坏设置时保留 invalid-UUID.json 副本，再恢复备份；来自未来 schema 的原文件禁止被旧版保存覆盖。
- 角色包可声明 schemaVersion=1、minimumAppVersion=x.y.z；旧包缺省仍接受，图集仍严格遵循 v2。单个不兼容/损坏包不会阻止其他角色加载，原包不删除。
- 在线角色逐个隔离失败；数据库写入等待事务提交完成。在线资源仍来自 main，尚未建设独立的版本化目录服务。
- 更新下载增加进程内互斥、唯一临时文件、连接/总时限、重新读取对应版本清单并核对哈希及大小；拒绝同版本和降级安装。失败释放锁并清理本次 partial 文件。
- 多进程各自启动安装器仍需原生验收；当前互斥锁不是跨进程锁。成功启动安装器不等于安装成功，尚未实现安装后健康检查/自动回滚。
- Agent 桥接读取最多 64 KB + 1，再解析鉴权；最多同时接纳 16 个连接。

## 3. 动作扩展

已将欢迎回来、鼓励加油、安慰一下、一起思考、休息一下五组组合动作接入共享控制器，提供停止按钮。每组有独立停顿、时长和短句。它们复用现有姿态，不宣称增加了真实新手势或骨骼动画。

## 验证与发布门槛

- `npm test`：播放抢占、暂停、取消、隐藏/拖拽阻断、时长、完整组合动作和角色版本兼容。
- `npm run build`：TypeScript 检查及 Vite 打包。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：配置迁移/备份恢复/未来配置保护、更新互斥与版本比较、桥接读取及连接上限。
- 主 Windows CI 已加入上述前端与 Rust 测试，原有资源校验和 MCP 握手冒烟保留。

仍需 Windows 实机验收：组合动作期间 Agent 成功/报错；连点与拖拽落地；隐藏再显示；切换角色；AI 请求期间关闭开关；多显示器缩放；真实旧版安装升级、下载断网恢复与安装失败。当前自动化覆盖不替代这些原生交互验收。
