# 芙宁娜自主需求循环

## 参考依据

参考开源 [VPet](https://github.com/LorisYounger/VPet)，已读取其 README 与 [MainLogic.cs](https://github.com/LorisYounger/VPet/blob/main/VPet-Simulator.Core/Display/MainLogic.cs)。该项目区分 Strength、StrengthFood、StrengthDrink 和工作/睡眠状态，按 TimePass 更新消耗/恢复。借鉴“状态需求驱动行为、按实际时间产生效果”的思路，没有复制其代码、素材或数值，也没有引入商店、疾病、经济系统。

## 当前实现

- 状态：体力、口渴、饥饿；以角色来源和ID区分运行期状态。当前只模拟内置芙宁娜，重启不持久化。
- 活动与动画分开：执行步骤显式标注实际活动，未标注的手动动作沿用语义映射；真实移动由移动控制器提供。每250ms在共享时钟采样，并在协调器活动切换时立即结算上一段。规划成功、被拒绝或尚未执行均不直接恢复体力。
- 走动消耗体力，跳跃/挥手/庆祝等活动消耗更快；休息和小憩恢复体力。同样的等待画面可表示观察、空闲或休息，分别按对应活动计算；观察轻微消耗体力，不因画面静止而被算成休息。尚未新增玩具或小游戏。
- 体力≤35%进入恢复，≥70%退出；≤22%优先小憩，否则坐下。疲劳时取消当前自主漫步/接近，禁用新的漫步和停靠候选；手动动作优先级保留。
- 口渴≥65%选择茶，饥饿≥65%选择蛋糕；各自降到≤25%才退出，避免阈值附近反复切换。严重疲劳优先于饮食。
- 实际需求恢复在同一个可取消协调器会话内持续到目标满足：体力70%，口渴/饥饿25%。普通后台行为让位；用户操作和智能体仍按原优先级抢占。普通短休息不进入持续恢复。
- 饮食/休息按实际活动秒数产生效果；停止、隐藏、拖拽或切换角色立即取消，中断后仅保留已结算收益，不记未来恢复。未满足的需求保留，下一次正常决策可继续恢复。隐藏/拖拽/下落暂停计量，长时间调度中断最多计2秒，避免离线惩罚。
- 普通空闲仍保留眨眼/好奇变化，自主计划仍使用原Utility评分；需求明确时提高休息评分，随机性只保留在可选日常行为中。

## 初始调参

体力初始78%。每秒走动消耗0.45个百分点，活跃互动0.8，观察0.08；普通空闲恢复0.08，休息1.2，小憩2.4。从初始状态累计约96秒实际走动会进入恢复，实际墙钟时间取决于停顿。口渴/饥饿从10%开始，纯空闲下约13/26分钟到达65%阈值，活动会加快。茶每秒降低16个百分点口渴，蛋糕每秒降低15个百分点饥饿。均为本项目第一版参数，待桌面体验调整。

自动决策由“自主行为”总开关控制，“允许走动”和“允许停靠”是独立许可；不开走动也能喝茶和休息。旧配置沿用原自主移动开关的开启状态。手动动作仍能改变需求，Agent保留原反馈动作。

窗口停靠改为体力35%～55%、没有更急迫需求时的就近休息候选，不再随机探索窗口。只选360逻辑像素内可容纳角色的顶部，保留原生窗口前后顺序排除已枚举窗口的遮挡；顶部没有空间时不转向窗口内部或随机漫步。脚底按舞台底部8逻辑像素的偏移对齐，停留12秒，约96ms检查一次跟随；窗口突然移动、关闭或被遮挡时退出。当前检测仍是矩形近似，不处理未枚举的工具浮层或不规则窗口轮廓。

## 验证

前台活动窗口通过Windows前台句柄标识。每次选择停靠目标时仅有20%机会保留该窗口候选，其他窗口不受此概率过滤影响；已停靠后的跟随不重复抽签，避免随机退出。

防打扰：活动窗口被概率跳过后冷却60秒（即使切到后台也保留）；鼠标距候选角色矩形不足180逻辑像素时不新建停靠，接近途中亦复查。实际拖动后5分钟不自主移动，优先在用户放置的位置进行日常动作；点击不产生该限制。从已停靠窗口拖走时记录该窗口5分钟禁返。记忆仅在本次运行有效。桌面底部24逻辑像素范围不主动寻找窗口休息，适度疲劳提高原地休息评分，窗口停靠作为次要选择。已停靠不因焦点变化或鼠标短暂经过而突然退出。

本轮147项前端测试与构建通过，新增8项覆盖活动与画面分离、实际执行优先与暂停、持续恢复、饮食退出目标、抢占/停止/隐藏/拖拽取消、后台让位、等待活动清除和仅真实需求触发恢复。既有角色隔离、停靠、重力、注视及取消迟到任务回归通过。本轮未新增心情或持久化。Windows安装包尚未包含本轮源码，需要重新打包后验收。
