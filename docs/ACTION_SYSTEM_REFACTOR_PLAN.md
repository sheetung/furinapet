## 1. 目标与边界

把“为什么做动作”“谁能执行”“执行多久”“播哪张图”“窗口如何移动”分开。新增动作应主要修改动作目录和角色素材定义，而不是同时改菜单、计时器、兼容判断和 PetView。

必须保留：点击挥手、拖动到目标位置后开心跳、自动漫步、窗口依附、重力下落、视线跟随、Agent/插件反应、停止动作、角色切换。

本轮不做：新物理引擎、新插件协议、养成数值、网络同步、复杂动作编辑器、自动资源压缩和新美术生成。已画素材的接入与执行器重构分批验收，避免把素材问题与调度问题混在一起。

## 3. 目标分层

```text

                    │ ActionRequest
                    ▼
             动作协调器 Coordinator
          优先级、阻断、会话所有权、取消
              ┌─────┴─────┐

       动作步骤执行器    移动控制器 Locomotion
       时间线与停顿     拖动/下落/漫步/依附
```

## 4. 统一数据契约

建议先用TypeScript类型，不引入新状态机依赖。

```ts
type ActionStep =
  | { kind: 'clip'; clipId: string; completion: 'once' | 'timed'; holdMs?: number; durationMs?: number; message?: string }
  | { kind: 'wait'; durationMs: number }
  | { kind: 'move'; target: Point; mode: 'walk' | 'approach' };

interface ActionRequest {
  requestId: string;
  actionId: string;
  source: 'user' | 'agent' | 'background';
  steps: readonly ActionStep[];
}

type ActionResult =
  | { status: 'completed' }
  | { status: 'rejected'; reason: 'blocked' | 'lower-priority' | 'invalid' }
  | { status: 'cancelled'; reason: 'replaced' | 'drag' | 'hidden' | 'character-change' | 'stopped' }
  | { status: 'failed'; reason: string };
```

以上是拟定契约，不是当前接口。对外IPC继续保留现有 `Reaction`，由适配器映射为内部动作；内部clipId不暴露为公共v2图集行号。

### 时长规则

- `once`：实际角色clip全部播完，再追加 `holdMs`；不要用业务代码手填帧总时长。
- `timed`：用于呼吸、小憩等可循环动作，必须给有限的持续时间。
- `wait`：保留会话控制权，不默认切回idle；若需要中立停顿，显式插入idle步骤。
- `move`：以到达、取消或失败结束，不用固定动画时长判断是否移动完成。
- 帧采样和步骤进度使用同一单调时间源；定时器只负责唤醒。迟到时按经过时间定位帧，不补播积压帧。
- 临时保持旧接口时，适配器负责“旧时长下限＋完整单次动作”的转换，不能把兼容逻辑分散到各调用点。

### 角色兼容

- 先解析角色能力和降级clip，再计算实际执行时长。
- 其他角色没有饮茶/蛋糕等素材时，使用明确配置的基础动作，不读取芙宁娜图集。
- 缺失或加载失败的素材回退中立帧并结束/降级，不无限持有执行权。
- 同一clip共享缩放；裁切位置与显示锚点分开。腾空位移不得被逐帧脚底对齐消除，坐姿晃腿也不应通过对齐最低脚点导致身体上下漂移。

## 5. 执行与中断规则

优先级沿用用户100、Agent20、后台10；低优先级拒绝，同优先级新请求替换旧请求。暂不增加动作队列，避免交互结束后补播过时动作。

每个会话拥有唯一ID、取消信号和可清理的计时器。所有异步返回、位置提交、帧更新都检查会话ID；旧会话只能清理自己的资源。

| 事件 | 行为 |
| --- | --- |
| 新用户动作 | 取消旧会话，开始新动作；避免先闪一帧idle |
| 停止 | 清理步骤/等待/移动资源，回中立 |
| 拖动开始 | 取消动作和自主移动，设置drag阻断，交给原生拖动 |
| 拖动释放 | 根据实际位移决定是否落地；阻断持续到落地完成，再播放一次开心跳 |
| 隐藏 | 取消动作和移动；hidden阻断独立于drag，不可互相解除 |
| 角色切换 | 取消旧会话，解析新素材，重置帧播放器 |
| 到达目标 | 结束移动会话，进入停留或中立；不能只停动画却继续改位置 |
| 异常 | 清理会话，返回failed；旧异常不得终止后来启动的会话 |

快照至少包含：会话ID、来源、actionId、步骤索引、执行状态、当前clip、剩余时间、阻断原因、最后结束原因。先用于预览与调试，不另做监控平台。
