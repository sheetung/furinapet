## 构建与复现

本轮实际运行 Tauri/WebView2 调试可执行文件，内嵌构建产物，不使用 Vite dev server。
尚未制作或安装 NSIS 包，不等于发布验收。

```powershell
$env:VITE_PET_RENDERER='rigged'
npx tauri build --debug --no-bundle --ci --config src-tauri/tauri.s5-qa.json
& .\src-tauri\target\debug\furina-desktop-pet.exe --show-control-center
```

QA 配置只将 beforeBuildCommand 换成 npm run build，避免当前环境的 pnpm
尝试重建已有 node_modules。正式 tauri.conf.json 不变。
--show-control-center 仅 debug_assertions 构建有效，不修改保存的启动/可见性设置。
VITE_PET_RENDERER 仅在当前构建进程启用，正式默认仍为 sprite。
